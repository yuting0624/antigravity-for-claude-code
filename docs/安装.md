# 安装指南

> 把 **Antigravity for GLM Code**（pi 包）装到你自己的机器上。全程约 10 分钟。
>
> 角色回顾：**大脑** = pi 里跑的模型（推荐 GLM）；**执行器** = 干重活的（本地引擎如 omlx/Ollama，或 Gemini 的 agy CLI）。至少配一个执行器。

---

## 1. 前置条件

| 组件 | 说明 | 必需 |
|---|---|---|
| [pi coding agent](https://github.com/badlogic/pi-mono) | `npm install -g --ignore-scripts @earendil-works/pi-coding-agent` 或 `curl -fsSL https://pi.dev/install.sh \| sh` | ✅ |
| Node.js ≥ 20 | pi 运行时（扩展需要） | ✅ |
| python3 + curl | 包装脚本的 JSON 处理与 HTTP（macOS 自带） | ✅ |
| 大脑模型凭据 | 推荐 GLM：[智谱开放平台](https://open.bigmodel.cn) 编程套餐 API Key | ✅ |
| 本地推理引擎 | omlx / Ollama / LM Studio / llama.cpp / vLLM 任一 | 执行器二选一 |
| Antigravity CLI (`agy`) | Gemini 执行器，见 [antigravity.google/docs/cli-using](https://antigravity.google/docs/cli-using) | 执行器二选一 |

## 2. 获取并安装本包

### 方式 A：从 git 安装（推荐，依赖自动处理）

```bash
pi install git:github.com/<发布者>/antigravity-for-glm-code
```

pi 会克隆到 `~/.pi/agent/git/` 并自动执行 `npm install --omit=dev` 安装运行时依赖（typebox）。

### 方式 B：本地目录（自己改代码 / 未发布到 git）

```bash
git clone <仓库地址> ~/antigravity-for-glm-code
cd ~/antigravity-for-glm-code
npm install                      # ⚠️ 本地路径方式不会自动装依赖，必须手动执行
pi install ~/antigravity-for-glm-code
```

> `pi install` 只把路径登记进 settings（不复制文件），所以以后 `git pull` 更新代码即生效，无需重装。

### 方式 C：临时试用（不落盘）

```bash
cd antigravity-for-glm-code && npm install
pi -e .        # 仅本次会话加载扩展/技能/命令模板
```

**验证装载成功**：启动 `pi` 时，顶部横幅应列出本包的 extension / skills / prompts；同时弹出健康检查通知。

## 3. 配置大脑（GLM）

三种方式任选其一：

### 方式一：登录内置智谱 Provider（最简单）

```
pi /login     # 选择 ZAI Coding Plan (China)，粘贴编程套餐 Key（国际版选 ZAI Coding Plan）
/model        # 选择 glm 型号（pi --list-models zai-coding-cn 查看可用 id）
```

`/model` 的选择会被记住；想固定默认值也可以直接改 `~/.pi/agent/settings.json`：

```json
{ "defaultProvider": "zai-coding-cn", "defaultModel": "glm-5.3" }
```

### 方式二：环境变量

```bash
export ZAI_CODING_CN_API_KEY="<你的智谱编程套餐 Key>"    # 国际版用 ZAI_API_KEY
pi --model zai-coding-cn/glm-5.3
```

### 方式三：自定义 Anthropic 兼容端点

写入 `~/.pi/agent/models.json`：

```json
{
  "providers": {
    "glm": {
      "baseUrl": "https://open.bigmodel.cn/api/anthropic",
      "api": "anthropic-messages",
      "models": [ { "id": "glm-4.6" }, { "id": "glm-5.3" } ]
    }
  }
}
```

> 说明：本包对大脑无硬性绑定——理论上任何 pi 能加载的模型都能当指挥者；文档与策略以 GLM 为基准。

## 4. 配置执行器（二选一起步）

### 4a. 本地执行器（免费 · 私密 · 离线）

**omlx 引擎用户：零配置。** 本包默认即指向 `http://127.0.0.1:8000/v1`、默认模型 `Ornith-1.5-35B-A3B-MLX-4bit`、API key 内置兜底（仅对该端点生效）。保证 `omlx serve` 在跑即可。

**其他引擎用户**：设环境变量覆盖（写进 shell profile）：

```bash
# 例：Ollama
export LOCAL_DELEGATE_BASE_URL="http://localhost:11434/v1"
export AGY_OPTION_LOCAL_TIER_FAST="qwen2.5-coder:7b"
export AGY_OPTION_LOCAL_TIER_THINK="qwen3:14b"
# Ollama 无需 key；LM Studio 默认 http://localhost:1234/v1；vLLM 默认 http://localhost:8000/v1
# 有鉴权网关（如 omlx）需要 LOCAL_DELEGATE_API_KEY —— 持久化放仓库外的本地文件，脚本会自动加载：
#   mkdir -p ~/.config/antigravity-for-glm
#   printf 'export LOCAL_DELEGATE_API_KEY="<key>"\n' > ~/.config/antigravity-for-glm/env
#   chmod 600 ~/.config/antigravity-for-glm/env
```

| 变量 | 默认值 | 说明 |
|---|---|---|
| `LOCAL_DELEGATE_BASE_URL` | `http://127.0.0.1:8000/v1`（omlx） | 裸 host:port 自动补 `/v1` |
| `AGY_OPTION_LOCAL_TIER_FAST` / `_TIER_THINK` | `Ornith-1.5-35B-A3B-MLX-4bit` | fast/think 档模型 |
| `LOCAL_DELEGATE_API_KEY` | 空（从环境或 `~/.config/antigravity-for-glm/env` 读取） | 鉴权网关（omlx 等）需要；切勿写进仓库 |
| `LOCAL_SEARXNG_URL` | 空 | 配置后本地搜索走你的 SearXNG |

### 4b. agy 执行器（Gemini · 代理能力）

```bash
# 安装并首次登录（浏览器授权）
agy models      # 能列出模型即认证成功
```

未安装也不影响本地执行器的全部功能；只是少了「读写仓库文件、终端命令、联网搜索工具」这类代理式委派。

## 5. 验证安装

```
/agy-setup          # 在 pi 会话里
```

或命令行：

```bash
~/antigravity-for-glm-code/bin/agy-doctor
```

预期输出：brain 一行显示 GLM/ZAI ✓ → local executor 探活 ✓ 且默认模型 present ✓ → 各脚本 executable ✓。任何 ✗ 都会附精确修复命令。

（可选）跑一遍无依赖测试套件确认一切正常：`bash tests/run-tests.sh`。

## 6. 开始使用

直接启动，然后正常说话即可——分工是自动的：

```bash
pi
```

| 你说 | 发生什么 |
|---|---|
| “给 payments 模块生成完整单测” | GLM 判定为批量任务 → 调 `delegate` 工具（local 后端生成测试并落盘）→ 亲自跑 pytest 验收 → 汇报 |
| “评审当前 diff” | 默认走本地后端（diff 不出机器），GLM 仲裁结论 |
| `/agy-local …` `/agy-delegate …` `/agy-review …` | 显式指定后端/任务的快捷命令 |
| 长任务 | GLM 用 `job` 工具后台化，`/agy-status`、`/agy-result` 收割 |

原理细节见 [docs/原理.md](原理.md)；完整手册见 [docs/使用指南.md](使用指南.md)。

## 7. 常见安装问题

| 症状 | 处理 |
|---|---|
| 启动横幅没有本包的 extension/skills/prompts | 确认 `pi list` 中有该包；方式 B 是否漏了 `npm install`（缺 typebox 时扩展无法加载） |
| 项目目录首次加载被询问是否信任 | 选信任即可（pi 对含项目级资源目录的标准流程） |
| doctor 显示 brain 为默认端点 | 完成第 3 步任一方式；重启 pi 生效 |
| 本地委派报“服务不可达” | 引擎没在跑：`ollama serve` / LM Studio 打开 Server / `omlx serve`；或核对 `LOCAL_DELEGATE_BASE_URL` |
| 报“模型不存在”（退出码 14） | `curl -s $BASE/models` 对照服务实际模型名，改 `AGY_OPTION_LOCAL_TIER_*` 或拉取模型 |
| Windows 上 agy 无头挂死 | 用 WSL/macOS/Linux 做 headless 委派（wrapper 已有墙钟保护兜底） |
